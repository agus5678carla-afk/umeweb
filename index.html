Problemática detectada en pasantías

Dispersión de legajos del personal, carga manual repetitiva, falta de estandarización de puestos por servicio y demoras en el seguimiento de postulantes e inducción.

Propuesta

Una aplicación web autónoma, exportable a CSV, que ordene la gestión de RR.HH. La tecnología es soporte operativo: la entrevista presencial y el criterio humano se mantienen.

Guía de Uso

  1. Carga de Legajos: completá el formulario y guardá.
  2. Nóminas: revisá, filtrá, exportá a CSV o imprimí.
  3. Relevamiento de Puestos: las jefaturas describen cada perfil.
  4. Filtración de CVs: cargá postulantes y citá a entrevista presencial.
  5. Plan de Inducción: checklist de bienvenida con constancia imprimible.

En el portal en línea los datos se guardan en una base compartida: todo el personal habilitado ve lo mismo. En cada formulario, el botón “Completar con ejemplo” muestra qué escribir.

Despliegue Online

Opción 1: Netlify Drop

Guardá este archivo como index.html, entrá a drop.netlify.com y arrastralo. Obtenés una URL pública al instante.

Opción 2: Vercel / GitHub Pages

Subí el archivo a un repositorio de GitHub e importalo desde vercel.com.

Opción 3: Servidor intranet UME

Alojalo en el servidor web local (Apache / IIS) para máxima privacidad.
